---
title: NativePHP Mobile 설치 방법 (Installation)
---
> 핵심 요약  
> Laravel 프로젝트에 NativePHP를 설치하면 모바일 앱(iOS/Android) 개발 환경이 자동으로 구성된다.

---
## 1. 설치 명령 실행

Laravel 프로젝트 루트에서 아래 명령어 실행

```bash
php artisan native:install
```

- NativePHP 설치 및 초기 설정 자동 수행
    
- iOS / Android 앱 빌드 환경 구성까지 포함 ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))
    

---

## 2. ICU 옵션 선택

설치 과정 중 선택 옵션이 등장

- `ICU 포함`: `intl` 확장 필요할 때 (예: 다국어 처리, Filament 사용 시 필수)
    
- `ICU 미포함`: 일반적인 경우 기본 선택
    

특히 **Filament 사용 시 반드시 ICU 포함 필요** ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))

---

## 3. nativephp 디렉토리 생성

설치 후 Laravel 프로젝트 구조 변화

```
/nativephp
/config/nativephp.php
```

### 역할

- iOS / Android 네이티브 앱 프로젝트 파일 포함
    
- 앱 빌드 및 실행에 필요한 핵심 구조
    

### 중요한 특징

- 직접 수정할 필요 없음
    
- 업데이트 시 재생성됨 (`--force` 옵션)
    

```bash
php artisan native:install --force
```

따라서 `.gitignore`에 추가 권장 ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))

---

## 4. Apple Developer Team ID 설정 (iOS)

iOS 빌드 시 필요

`.env` 파일에 설정

```env
NATIVEPHP_DEVELOPMENT_TEAM=YOUR_TEAM_ID
```

- Apple Developer 계정에서 확인 가능 ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))
    

---

## 5. 설치 후 핵심 흐름

설치 이후 개발 흐름은 다음과 같이 이어짐

1. NativePHP 설치
    
2. Laravel 앱 그대로 사용
    
3. 모바일 앱으로 빌드 및 실행
    

NativePHP가 대부분의 네이티브 설정을 자동 처리

---

## 정리

- `php artisan native:install` 한 번으로 모바일 환경 구축
    
- 네이티브 코드 직접 수정 없이 Laravel 그대로 사용 가능
    
- `nativephp` 디렉토리는 자동 생성 + 재빌드 구조
    
- ICU 옵션은 기능에 따라 선택 (Filament 사용 시 필수)
    

---

## 실무 관점 핵심 포인트

- Laravel + Livewire 기반 그대로 모바일 앱 전환 가능
    
- 별도 React Native / Flutter 학습 없이 앱 개발 가능
    
- DevOps 관점에서 "웹 → 모바일" 확장 비용이 매우 낮음
