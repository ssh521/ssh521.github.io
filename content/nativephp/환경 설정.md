title: NativePHP Mobile 환경 설정 (Environment Setup)
---
> NativePHP Mobile은 실제 디바이스 없이도 시뮬레이터/에뮬레이터로 개발이 가능하지만, 최종 배포 전에는 반드시 실기기 테스트가 필요하다.


## 1. 기본 개발 환경 개념

NativePHP Mobile은 iOS와 Android 앱을 빌드하기 위해  다음과 같은 환경을 기반으로 동작한다.

- iOS → Xcode + iOS Simulator
- Android → Android Studio + Emulator
- Laravel 기반 PHP 애플리케이션

즉, 기존 Laravel 개발 환경 위에 **모바일 빌드 도구(Xcode, Android Studio)**가 추가되는 구조다.

또한 실제 디바이스 없이도 개발 및 테스트가 가능하다. ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/environment-setup?utm_source=chatgpt.com "Environment Setup"))

---

## 2. 에뮬레이터(가상 디바이스) 설정

### Android 에뮬레이터 설정

Android Studio에서 Virtual Device가 반드시 필요하다.

문제 상황:

- `"No AVDs found"` 에러 발생

해결 방법:

1. Android Studio 실행
2. Virtual Devices 메뉴 이동
3. 새로운 디바이스 생성

이 설정이 없으면 앱 실행 자체가 불가능하다. ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/environment-setup?utm_source=chatgpt.com "Environment Setup"))

---

## 3. 실기기 테스트 (권장)

NativePHP는 시뮬레이터만으로도 개발 가능하지만,  
스토어 배포 전에는 반드시 실기기 테스트가 필요하다.

### iOS 실기기 테스트 조건

- Developer Mode 활성화
    
- Apple Developer 계정 등록
    
- 디바이스를 계정에 등록
    

### Android 실기기 테스트 조건

- 개발자 옵션 활성화
    
- USB 디버깅(ADB) 활성화
    

이 과정을 통해 실제 모바일 환경에서 앱 동작을 검증할 수 있다. ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/environment-setup?utm_source=chatgpt.com "Environment Setup"))

---

## 4. 핵심 정리 (실무 관점)

환경 설정의 핵심은 단순하다.

1. Laravel 프로젝트 준비
2. Xcode / Android Studio 설치
3. 에뮬레이터(AVD) 생성
4. 필요 시 실기기 연결 및 디버깅 활성화

즉, **웹 개발 + 모바일 빌드 환경 결합**이라고 이해하면 가장 정확하다.

---

## 5. 실무에서 중요한 포인트

### 1) 초반은 에뮬레이터로 빠르게 개발

- UI, 로직 검증 속도 빠름

### 2) 중반부터 실기기 테스트 병행

- 카메라, 센서, 성능 확인 필수

### 3) 배포 전 반드시 실기기 검증

- iOS / Android 각각 테스트 필요

---

## 6. 정리

NativePHP Mobile의 환경 설정은 복잡해 보이지만 구조는 단순하다.

- 웹 개발(Laravel) + 모바일 빌드 도구
- 에뮬레이터로 빠르게 개발
- 실기기로 최종 검증

이 흐름만 이해하면 대부분의 문제를 해결할 수 있다.
