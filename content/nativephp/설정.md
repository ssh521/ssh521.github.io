# NativePHP Mobile 설정(Configuration) 완전 정리

> 핵심 요약  
> Laravel 내부 설정만으로 모바일 앱 구성이 가능하며, 대부분의 설정은 `config/nativephp.php`에서 관리된다.

---

## 1. 전체 개념

NativePHP Mobile은 **Xcode나 Android Studio를 직접 수정하지 않고**,  
Laravel 프로젝트 내부에서 대부분의 설정을 처리하도록 설계되어 있다. ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/configuration?utm_source=chatgpt.com "Configuration - NativePHP mobile v3"))

즉,

- 모바일 앱 설정 = Laravel 설정 파일
    
- 네이티브 코드 수정 최소화
    

라는 구조를 가진다.

---

## 2. 핵심 설정 파일 구조

### config/nativephp.php

모든 핵심 설정은 아래 파일에서 관리된다.

```bash
config/nativephp.php
```

이 파일에서는 다음과 같은 항목을 설정할 수 있다:

- 앱 이름 / 앱 ID
    
- 번들 식별자 (iOS / Android)
    
- 앱 버전
    
- 빌드 설정
    
- 아이콘 및 스플래시
    
- 네이티브 동작 옵션
    

기본값이 제공되며, 필요 시 override 가능하다. ([NativePHP](https://nativephp.com/docs/mobile/1/getting-started/configuration?utm_source=chatgpt.com "Configuration - NativePHP mobile v1"))

---

## 3. 환경 변수(.env) 기반 설정

일부 설정은 `.env`로도 제어 가능하다.

예시:

```env
NATIVEPHP_DEVELOPMENT_TEAM=XXXXXX
```

- iOS 개발팀 ID 설정
    
- 빌드/서명 관련 설정 분리 가능
    

→ 환경별(dev / staging / production) 분리 설계에 유리 ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))

---

## 4. NativePHP 디렉토리 구조

설치 후 생성되는 폴더:

```bash
/nativephp
```

특징:

- iOS / Android 네이티브 프로젝트 포함
    
- 자동 생성 및 재생성됨
    
- 직접 수정 비권장
    

주의사항:

- 업데이트 시 재생성됨 (`--force`)
    
- Git 관리 제외 권장 (`.gitignore`)
    

```bash
php artisan native:install --force
```

→ 즉, “빌드 결과물 디렉토리”로 이해하는 것이 핵심 ([NativePHP](https://nativephp.com/docs/mobile/3/getting-started/installation?utm_source=chatgpt.com "Installation - NativePHP mobile v3"))

---

## 5. 설정 철학 (중요 포인트)

NativePHP 설정의 핵심 철학은 다음 3가지로 정리된다.

### 1) Laravel 중심 설계

- 모든 설정을 Laravel에서 처리
    
- Dev 경험 통일
    

### 2) 기본값 중심 (Convention over Configuration)

- 대부분 자동 설정
    
- 필요한 경우만 커스터마이징
    

### 3) 네이티브 코드 최소 개입

- Swift / Kotlin 직접 수정 거의 없음
    
- 유지보수 비용 감소
    

---

## 6. 실무 적용 관점 정리

### 추천 구조

```bash
config/nativephp.php   → 앱 설정
.env                  → 환경 분리
nativephp/            → 빌드 결과 (ignore)
```

### 실무 전략

- 앱 설정은 config로 통합 관리
    
- 환경별 값은 .env로 분리
    
- nativephp 디렉토리는 절대 수정하지 않기
    

---

## 7. 핵심 정리

- NativePHP Mobile은 **Laravel 기반 설정 중심 구조**
    
- `config/nativephp.php`가 핵심
    
- `.env`로 환경 분리 가능
    
- 네이티브 프로젝트는 자동 생성 및 재생성
    
- 네이티브 개발 지식 없이 앱 구성 가능
